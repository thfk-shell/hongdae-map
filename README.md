# 홍대 느슨지도 (v0.3 개발판 — 브이월드 지도)

홍대·연남·상수·합정에서 친구들과 갈 곳을 고르는 모바일용 큐레이션 지도예요.
서버·로그인 없이 파일만으로 돌아가는 정적 웹사이트입니다.

## 바로 열어 보기 (v0.2.1에서 바뀜)

**`index.html`을 더블클릭해서 열지 마세요.** 그렇게 열면 주소가 `file://`로 시작하는데, 이때 OpenStreetMap 지도 서버가 요청을 거절("403 Access blocked")하거나 다른 지도에 경고 글자가 찍힐 수 있어요.

- **Windows**: 폴더의 `지도 실행하기(Windows).bat`을 더블클릭 → 검은 창이 뜨고 브라우저가 `http://localhost:8787/index.html`로 열려요. 검은 창은 지도를 보는 동안 켜 두세요. (설치할 것 없음. 처음에 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행")
- **Mac**: `지도 실행하기(Mac).command`를 더블클릭 (처음엔 오른쪽 클릭 → 열기). python3가 없으면 안내가 나와요.
- **Node.js가 있다면**: 이 폴더에서 `node tools/serve.js`
- 휴대폰에서 보려면 인터넷에 올려야 해요(아래 "GitHub Pages에 올리기", 승인 후 진행).
- 지도 배경이 안 나오면 주소 끝에 `?mapdebug`를 붙여 열어 보세요 (예: `http://localhost:8787/index.html?mapdebug`). 지도 위에 어느 서버가 어떤 이유로 실패했는지 나와요. 그 글을 그대로 복사해서 알려 주면 원인을 바로 찾을 수 있어요.
- 지도 배경이 끝내 안 되면 역 출구와 동네 이름만 있는 **간단한 지도**로 바뀌고, 이유를 화면에 알려 줘요. 장소 핀과 목록은 그대로 쓸 수 있어요.

## 브이월드 지도 쓰기 (v0.3에서 추가)

기본 지도를 국토교통부 **브이월드(VWorld)** 로 바꿨어요. 브이월드는 인증키가 있어야 지도 그림을 줘요.

- **키가 없으면**: 브이월드를 건너뛰고 예전처럼 OpenStreetMap 지도를 보여 줘요. 사이트는 그대로 쓸 수 있어요.
- **키를 넣는 곳**: `data/map-key.js` 파일의 `vworld: ''` 따옴표 안.
- **파일을 고치지 않고 시험만 하기**: 주소 끝에 `?vwkey=발급받은키`를 붙여 한 번 열면 그 브라우저에 저장돼요(주소창에서는 바로 지워짐). 지우려면 `?vwkey=clear`.
- **흰색 지도와 비교**: 주소 끝에 `?map=white` (예전 지도는 `?map=osm`).
- 키가 있는데 지도가 안 나오면 화면 위에 이유가 잠깐 뜨고 OpenStreetMap으로 바뀌어요. 자세한 이유는 `?mapdebug`.
- 브이월드 키는 웹 브라우저에 그대로 보이는 **공개용 키**예요. 꼭 브이월드에서 사용할 사이트 주소(서비스 URL)를 등록해서 다른 사이트에서는 못 쓰게 해 두세요.
- 출처 표시(공공누리 제1유형)는 지도 오른쪽 위와 목록 맨 아래에 자동으로 나와요. 지우지 마세요.

## 할 수 있는 것

- 지도 + 아래에서 끌어올리는 장소 목록 (넓은 화면에서는 왼쪽 목록)
- 6개 카테고리, 빠른 필터(지금 영업 중·실내·저렴한 곳·늦게까지·기간 한정), 태그, 테마 카드
- 검색: 이름·작품·메뉴·태그·주소 / 초성 검색(예: `ㅇㅂㄷ` → 오버딥)
- 장소 상세: 한 줄 추천 이유, 후기 요약(좋다는 말·아쉽다는 말·추천 대상·현실 정보), 후기 원문 링크, 영업시간, 확인이 필요한 점, 정보 출처와 확인 상태
- "이 근처 둘러보기": 그 장소 기준 도보 5·10분 원을 그리고 가까운 순으로 다시 정렬
- 하트로 저장 → 저장 목록에서 가까운 순서로 이은 코스, 단톡방용 글 복사, 공유 링크 복사
- 네이버지도·카카오맵으로 바로 연결 (길찾기는 각 앱에서)

## 장소 데이터 고치기

`data/places.js`를 메모장 등으로 열어 고쳐요. `window.HM_PLACES =` 뒤는 JSON 형식이라 쉼표·따옴표를 지켜야 해요.

- 기본 목록에서 빼되 데이터는 남기려면: `"listed": false`, `"hiddenReason": "이유"`
- 확인이 필요한 점을 화면에 띄우려면: `"issues": ["설명"]`
- 직접 추정한 위치라면: `location.manual: true` (화면에 "위치 추정" 표시)
- 검증 상태: `verified`(공식 출처 확인) / `cross-checked`(여러 출처 일치) / `needs-check`(확인 필요). `verifiedAt`은 verified일 때만 날짜를 넣어요.
- 후기 요약(`review`)은 실제로 읽은 후기가 있을 때만 쓰고, `sourceCount`는 `sources` 개수와 같아야 해요.

고친 뒤 Node.js가 있다면 `node tools/validate.js`로 형식 오류를 검사할 수 있어요.

## GitHub Pages에 올리기 (사용자 승인 후 진행)

1. GitHub에서 새 저장소를 만들고 이 폴더 안의 파일을 전부 올려요.
2. 저장소 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 저장해요.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열려요.

## 알아둘 한계

- 장소 정보는 2026-10-16 웹 조사 기준이에요. 현장·전화 확인은 하지 않았어요.
- 도보 시간은 직선거리 × 1.3 ÷ 분당 70m로 어림한 값이에요.
- 저장 목록은 그 기기 브라우저에만 남아요(로그인 없음). 친구에게는 공유 링크로 보내요.
- 브이월드 키가 없거나 실패하면 쓰는 대비용 지도: OpenStreetMap 기본 타일을 먼저 쓰고, 서버가 거절하면 CARTO(OpenStreetMap 기반) 타일을 써요. 둘 다 무료지만 **소규모 사용**만 허용돼요(OSM 타일 사용 정책). 친구들과 시험해 보는 정도는 괜찮고, 공개해서 방문자가 많아지기 전에 MapTiler·카카오맵 등 키를 받는 지도 서비스로 바꿔야 해요. `data/settings.js`의 `tiles` 목록과 `js/map.js`만 바꾸면 돼요.
